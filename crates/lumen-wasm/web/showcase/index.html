Esta suite cazó un bug real antes que un usuario

El prototipo de sieve(1M) no terminaba: cada criba[m] = 0 clonaba el arreglo entero (O(n) por escritura → O(n²) en total). La corrección (opcode ArraySetVar, escritura in-place con semántica de copia intacta) lo dejó en ~1.2 s en nativo — y es exactamente lo que ejecuta el botón de arriba.

02

El JIT del binario nativo

target/release/lumen · LUMEN_JIT_LOG=1 · captura real
$ lumen run benchmarks/lumen/fib.nv [jit] 🔥 Hot function detected: 'fib' (50 llamadas) → JIT Tier-1 activado [jit] ✅ recursión nativa (registros): 'fib' (16 instrs) $ lumen run benchmarks/lumen/primes.nv [jit] 🔗 inlining de 'es_primo' en 'contar_primos' [jit] ✅ Tier-2 bucle nativo: 'contar_primos' (15 instrs) $ lumen run benchmarks/lumen/sieve.nv [jit] ✅ Tier-2 bucle nativo: 'bench_sieve' (47 instrs)

TIER-Rrecursión en registros

fib se recompila a recursión nativa sin frames de VM: 4.3 ms en la medición de referencia (~26× vs el intérprete, ~2× el C).

TIER-2bucles + inlining

es_primo se inlinea dentro de contar_primos y el bucle resultante pasa a código nativo. bench_sieve —el mismo código que corre arriba— también compila a Tier-2.

TIER-1funciones calientes

Tras 50 llamadas, cualquier función caliente se promueve a código máquina con Cranelift, delegando por shims al runtime.

En wasm32 no se puede generar código máquina en runtime, así que el build lumen-wasm se compila sin el backend JIT y corre la VM pura: misma semántica, distinta velocidad. Por eso los tiempos de tu navegador (abajo) son mayores que la columna nativa.

05

Por qué estos números son de fiar

1

Checksums exactos

Cada tarea imprime un valor calculado con implementaciones de referencia independientes. No hay tolerancia: o coincide, o falla.

2

Cinco lenguajes, un algoritmo

Mismo quicksort, misma criba, mismo mapa en benchmarks/{c,cpp,rust,python,lumen}. La comparación cruzada es justa por construcción.

3

Gate en CI

scripts/ci_bench_suite.py corre los 5 lenguajes en ubuntu/windows/macos en cada push y bloquea la release si un checksum diverge.
